# プッシュ通知の設定と確認の手順

## A. 準備（管理者が1回だけ）

1. アプリに管理者として入る（ログイン画面の「管理者の方はこちら」）
2. 管理者メニュー →「テスト用」→「通知の設定」の「**通知用の鍵を作る**」を押す
3. 表示された2つの値を、Vercel に登録する（下の B）
   - 秘密の鍵は、チャット・メール・LINE などに貼らないこと
   - 画面を閉じると同じ鍵は二度と表示されない。登録前に閉じてしまったら、もう一度作ればよい

## B. Vercel への登録

Vercel のプロジェクト →「Settings」→「Environment Variables」→ 追加ボタン で、次の2つを登録する。

| 名前（Key） | 値（Value） | 種類 |
|---|---|---|
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | ① 公開用の鍵 | Config |
| `VAPID_PRIVATE_KEY` | ② 秘密の鍵 | **Secret** |

- 使う場所（Environments）は、すでにある変数と同じ「Production」
- 2つとも登録したら「Deployments」→ 一番上の行の「…」→「Redeploy」（公開用の鍵はアプリの組み立て時に読み込まれるため、必ずやり直す）
- 反映後、管理者メニュー「テスト用」の「現在の状態」が「設定済み」になれば完了

## C. iPhone での確認（iOS 16.4 以降）

iPhone では、**ホーム画面に追加したアプリからだけ**通知を受け取れます（Safari のまま開いていると通知は使えません）。

1. Safari でアプリのURLを開く
2. 画面下の共有ボタン（四角から上向きの矢印が出ているマーク）→「ホーム画面に追加」→「追加」
3. ホーム画面にできたアプリのアイコン（名前は src/config/site.ts の appShortName）からアプリを開き、社員番号で入る
4. ホームで「お知らせが届いたら通知しますか？」→「通知を受け取る」→ iPhone の確認で「許可」
5. マイページ →「テスト通知を送る」→ 数秒〜1分で通知が届くか確認
6. 管理者がお知らせを投稿 → 「【事故速報】タイトル」の通知が届き、押すとそのお知らせが開くか確認
7. ホーム画面のアイコンの右上に、未読の件数（赤い丸の数字）が出るか確認
   - 出ない場合：iPhone の「設定」→「通知」→ アプリの名前 →「バッジ」をオン

## D. Android での確認（Chrome）

1. Chrome でアプリのURLを開く
2. 右上の「︙」→「ホーム画面に追加」（または「アプリをインストール」）
3. ホーム画面のアプリのアイコン（名前は src/config/site.ts の appShortName）からアプリを開き、社員番号で入る
4. ホームで「お知らせが届いたら通知しますか？」→「通知を受け取る」→「許可」
5. マイページ →「テスト通知を送る」→ 通知が届くか確認
6. 管理者がお知らせを投稿 → 通知が届き、押すとそのお知らせが開くか確認
7. アイコンの数字：Android では機種（ホーム画面のアプリ）によって、数字ではなく小さな点で表示されたり、表示されなかったりします

## うまくいかないとき

- 「通知の準備がまだできていません」：B の登録と Redeploy が済んでいない
- 「このスマホでは通知が『許可しない』になっています」：スマホの「設定」アプリで、このアプリ（Android は Chrome）の通知を許可する
- テスト通知が届かない：マイページで通知を一度オフ → オンにしてから、もう一度テスト
- ログアウトすると、そのスマホには通知が届かなくなります（別の人が同じスマホを使っても届かないように）。もう一度入ったら、マイページで通知をオンにしてください
