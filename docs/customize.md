# カスタマイズの手引き

自分たちの会社に合わせて、自由に変えて使ってください。
GitHub の画面上でファイルを直して保存（Commit）すると、Vercel が自動で作り直して、数分で反映されます。

## 1. アプリの名前・会社名・ロゴ（`src/config/site.ts`）

いちばんよく変えるところは、このファイル1つにまとめてあります。

| 項目 | 中身 |
| --- | --- |
| `appName` | アプリの名前（ブラウザのタブ・ログイン画面の見出し） |
| `appShortName` | ホーム画面のアイコンの下に出る短い名前 |
| `companyName` | 会社名（画面の上の帯に出ます） |
| `logoSrc` | 白抜きのロゴ画像（任意）。`public/` に画像を置いて `"/logo-white.png"` のように書く |
| `companies` | 所属会社の選択肢。グループ会社の社員も使うときに足す |

## 2. 色（`src/app/globals.css`）

ファイルの上の方にある「色」の部分を書き換えます。

- `--color-primary`：基調の色（ボタンや見出し）
- `--color-gold` / `--color-gold-line`：注意を引くところの色
- `--color-unread`：未読の印の色（赤）

## 3. アイコン（`public/icons/`）

ホーム画面に追加したときのアイコンです。同じ名前・同じ大きさの画像に差し替えてください。

- `icon-192.png`（192×192）、`icon-512.png`（512×512）
- `icon-maskable-512.png`（512×512。周りに余白を多めに）
- `apple-touch-icon.png`（180×180。iPhone 用）
- `badge-96.png`（96×96。通知の小さなマーク。白い絵柄で背景は透明）

## 4. お知らせのカテゴリ（`src/lib/types.ts`）

`CATEGORIES` に「事故速報」「安全・運行」「社内報」「総務」が入っています。名前を変えたり、増やしたりできます。
※「事故速報」は入力欄が特別（発生状況・原因・再発防止）なので、名前を変えるときは関係するところも直してください。

## 5. もっと大きく変えたいとき（AI に手伝ってもらう）

`CLAUDE.md` に、このアプリの作りと決まりごとをまとめてあります。
Claude Code などの AI に「CLAUDE.md を読んでから、〇〇を追加して」と頼むと、作りに合わせて直してくれます。
