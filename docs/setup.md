# 導入の手順（はじめての方向け）

プログラミングの知識がなくても、画面の操作だけで始められるように書いています。
かかる時間は30分〜1時間くらいです。費用は、どれも無料の範囲から始められます（会社で本格的に使う場合は、下の「費用について」を見てください）。

## 用意するもの

- パソコン（スマホだけでは、一部の操作がしにくいです）
- メールアドレス
- 次の3つのサービスのアカウント（すべて無料で作れます）
  - **GitHub**（プログラムの置き場所）：https://github.com
  - **Supabase**（データとログインの仕組み）：https://supabase.com
  - **Vercel**（アプリを動かす場所）：https://vercel.com

---

## 1. Supabase でデータベースを作る

1. Supabase にログインし、「New project」を押す
2. 名前（例：`driver-portal`）とデータベースのパスワードを決める。地域（Region）は **Northeast Asia (Tokyo)** を選ぶ
3. できたら、左のメニュー「**SQL Editor**」を開く
4. このプログラムの `supabase/setup.sql` を開き、**中身を全部コピーして貼り付け、「Run」を押す**
   - 「Success. No rows returned」と出れば成功です
5. 左のメニュー「**Authentication**」→「Sign In / Providers」で、「**Allow new users to sign up**」を**オフ**にして保存する
   - アカウントは管理者だけが作る決まりにするためです
6. 左のメニュー「**Project Settings**」→「**API Keys**」（または「API」）を開き、次の3つを控えておく
   - Project URL（`https://〜.supabase.co`）
   - `anon` `public` のキー（公開用のキー）
   - `service_role` のキー（**秘密のキー**。人に見せない・チャットなどに貼らない）

## 2. Vercel でアプリを公開する

1. GitHub で、このプログラムの「**Use this template**」→「Create a new repository」を押し、自分用のコピーを作る（非公開＝Private がおすすめ）
2. Vercel にログインし、「Add New…」→「Project」→ いま作った GitHub のコピーを選んで「Import」
3. 「Environment Variables」に、次の3つを入れる

   | 名前 | 値 |
   | --- | --- |
   | `NEXT_PUBLIC_SUPABASE_URL` | Project URL |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | `anon` `public` のキー |
   | `SUPABASE_SERVICE_ROLE_KEY` | `service_role` のキー（種類は **Secret** にする） |

4. 「Deploy」を押す。数分でアプリのアドレス（例：`https://〜.vercel.app`）ができます

## 3. 最初の管理者を登録する

1. ブラウザで `https://（アプリのアドレス）/setup` を開く
2. 氏名・社員番号・パスワードを入れて「最初の管理者を登録する」を押す
3. 管理者ログイン画面になるので、いま決めた**社員番号とパスワード**で入る

> この画面は、管理者がまだ1人もいないときだけ使えます。登録したあとは使えなくなります。

## 4. 会社に合わせて設定する

1. 管理者メニュー →「社員管理」→「**営業所の管理**」で、営業所を登録する（はじめは「本社営業所」が1つだけあります）
2. 「社員管理」で社員を登録する。人数が多いときは「CSVで取り込む」でまとめて登録できます
3. アプリの名前・会社名・ロゴ・色を変えるときは、[カスタマイズの手引き](./customize.md) を見てください

## 5. 通知を使えるようにする

[プッシュ通知の設定と確認の手順](./push-notifications.md) を見てください（管理者メニュー「テスト用」で鍵を作り、Vercel に登録します）。

## 6. ドライバーに使ってもらう

- ドライバーは、アプリのアドレスを開いて**社員番号だけ**で入れます
- iPhone は Safari の共有ボタン →「ホーム画面に追加」、Android は Chrome の「︙」→「ホーム画面に追加」で、アプリのように使えます

> **大事なこと**：ドライバーは社員番号だけで入れる作りです。社員番号を社外に出さないように注意してください。

## 費用について

- はじめは、どのサービスも無料の範囲で試せます
- 会社で本格的に使う場合は、次の点に気を付けてください
  - Vercel の無料プランは個人利用向けです。会社で使うときは有料プラン（Pro）が必要です
  - Supabase の無料プランには自動バックアップがありません。大事なデータを扱うなら有料プラン（Pro）がおすすめです
  - 料金は各サービスのページで確かめてください

## 事故報告書の読み取り（任意・AI）

事故速報の入力で、事故報告書の画像やPDFを AI（Anthropic 社の Claude）に読み取らせて、下書きを作る機能があります。
使うときだけ、Vercel に `ANTHROPIC_API_KEY`（Anthropic のコンソールで作る鍵）を **Secret** として登録してください。
登録しなければボタンは出ず、AI に何も送られず、費用もかかりません（使った回数の分だけ料金がかかります）。

## うまくいかないとき

- 画面に「データベースの設定がまだのようです」と出る：1-4 の `setup.sql` が実行できているか確かめる
- 「SUPABASE_SERVICE_ROLE_KEY が登録されていません」と出る：2-3 の登録を確かめ、Vercel で「Redeploy」する
- 環境変数を変えたら、必ず Vercel の「Deployments」→ 一番上の「…」→「Redeploy」を押す
